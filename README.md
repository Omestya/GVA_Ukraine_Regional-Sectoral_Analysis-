# Економічний розвиток України у 2014-2021 роках: динаміка валової доданої вартості, галузева та регіональна структура
## Опис дослідження
У статті досліджено економічний розвиток України протягом 2014-2021 років на основі аналізу валової доданої вартості, випуску та індексів фізичного обсягу ВДВ. Розглянуто динаміку номінальних показників, визначено провідні галузі економіки та регіони за внеском у формування ВДВ.
## Мета дослідження
- Проаналізувати динаміку ВДВ України у 2014-2021 роках.
- Визначити основні галузі та регіони, які формували економічний результат.
- Оцінити зміни фізичного обсягу виробництва в різних видах економічної діяльності.
## Інструменти
- Microsoft Excel - опрацювання та підготовка даних, об'єднання датасетів в один файл.
- Tableau - побудова графіків та візуалізація результатів.

## Висновки
У 2014-2021 роках в Україні спостерігалося зростання номінальної ВДВ, водночас її формування характеризувалося галузевою та регіональною нерівномірністю. Провідну роль відігравали торгівля, сільське господарство та переробна промисловість. Результати аналізу дали змогу визначити основні тенденції економічного розвитку та особливості розподілу ВДВ між регіонами й видами економічної діяльності.
## Джерела даних
Державна служба статистики України. Національні рахунки: статистичні дані щодо валової доданої вартості, випуску та індексів фізичного обсягу ВДВ за видами економічної діяльності й регіонами України. Офіційний вебсайт. URL: [https://www.ukrstat.gov.ua/](https://stat.gov.ua/uk/explorer).
